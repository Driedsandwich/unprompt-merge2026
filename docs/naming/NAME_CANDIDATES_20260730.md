## §1. 製品ファクトシート(命名の土台) — 入力として受領した前提

- 一言: **Intent Compiler**。曖昧な一文の制作依頼を、成果物を作らずに「その文がまだ決めていないこと(判断点)」3〜5枚のカードに爆散させる。各判断点に対照的な解釈の実生成サムネイル。
- 動詞は2つ: 決める(見本クリック) / 委ねる。一括: ランダム / AIおすすめ / 選び直し。
- 出力は成果物ではなく「意図の指示書(compiled brief)」。最初の一文のあと1文字もタイプしない。任意のAIに渡す=最初の一歩をブースト。
- 証明: 一文そのまま vs 指示書経由 の並置比較(実生成)。
- 射程: LP・メール・文章・画像プロンプト・動画プロンプト等、AI利用全般の初動。
- デザイン言語: 「朱と藍の製図」— 製図白+極薄方眼 / 朱=未決 / 藍=確定 / 鼠=委任 / 明朝ヒーロー / 角丸ゼロ / 爆散演出 / ダーク=夜の製図台。
- 提出先: MERGE 2026 AI Designathon。審査軸: AI Integration 30 / Innovation&UX 30 / Speed&Quality 20 / Feasibility 20。

## §2. 評価基準(100点) — 入力として受領した基準

## §6. 統合判定 — 評価(統合者)

### 6.0 保存すべき矛盾(平均化しない)

1. **審査の全会一致1位 UNSAID(249点)は、衝突 high のため推薦できない。** この矛盾は解消せず記録する。審査員たちが UNSAID に与えた評価——「名前=製品定義」「説明ゼロの直結」——は正しいままであり、UNSAID が負けたのではなく**外部世界(同名AI製品群)が先に席を取っていた**。Designathon 単発の場では審査1の言う通り「減点にならない」可能性もあるが、AKINDO 提出物は公開物であり、AI×対話ジャンルでの同名衝突は「他人の製品と誤認されるリスク」そのもの。よって規定通り除外する。
2. **UNSAID の意味論の正嫡は TACIT である。**「言われなかったこと/暗黙のこと」という同じ意味領域を、衝突ジャンルの異なる別の語で継承する。ただし衝突未確認+日本語話者への伝達弱の二重の未確定を抱える。
3. **Redline / SUBTEXT が持っていた「ワードマークがデザイン言語そのもの」という強みは、Refract が別経路(朱→藍のスペクトル)で継承する。**塗り分けの継承ではなく分光の継承。
4. Unprompt には内的緊張がある: 名前は体験の前半(ほどく)を指すが、製品の終点は「より強いプロンプト(指示書)」である。これは欠陥ではなく tagline で二拍にする——**"Unprompt first. Prompt better."**——ことで、緊張ごと製品の主張(作る前に、ほどく)になる。

### 6.1 最終推薦 1位: **Unprompt**

唯一の非-high。かつ「消去法の残り物」ではなく、この製品の4画面すべてに載って強い:

- **爆散画面**: 名前が演出の実況になる。一文=プロンプトが文字通り un- される(ほどけて判断点が立ち上がる)。画面で起きていることの動詞がそのまま製品名。誤読リスク(プロンプト削除ツール?)は、審査1・3の指摘通りこの画面の冒頭3秒が自力で潰す——名前の最大の弱点を、製品の最初の画面が構造的に防御する配置。
- **指示書画面**: "You unprompted 1 line into 5 decisions." と実測表示できる。un- の否定(朱=未決)が「決める/委ねる」で藍=確定に転じていく過程を、Un(朱)+prompt(藍)のワードマーク塗り分けが最初から予告している。
- **並置証明**: 左「prompted as-is」/右「unprompted → briefed」。比較のラベルが名前から自動生成され、"Unprompt first. Prompt better." が証明画面のキャプションとして完結する。
- **朱と藍の製図**: 小文字始まりでない「Unprompt」の明朝ワードマークは角丸ゼロの製図面に立つ。かつ審査軸 AI Integration 30 に対し、業界中心語 prompt の否定形という名前自体が「AIとの関係を再設計した」という主張になる——名前がプレゼンの第一スライドを兼ねる。
- 拡張性: 文章専用に見えない(prompt は画像・動画AIの共通語)。動詞化最強(Unprompt it first)。「unprompted brief」等の機能名展開も効く。

**採用条件(事実確認のゲート)**: (a) unprompt.ai / UnPrompt AI の提供終了の裏取り(「終了との情報あり」は伝聞段階=未確認)。(b) 商標・主要ストアでの再検索。(c) 表記は Unprompt(頭大文字のみ)を推奨、ワードマークでは Un=朱/prompt=藍。

### 6.2 対抗案

- **対抗A: Refract**(審査1で73点、衝突未確認)
  爆散画面の隠喩として全候補中最も美しい——一文が判断点スペクトルへ分光する。しかも光学の分光は文字通り**赤(朱)から青(藍)への帯**を生む: 朱=未決から藍=確定へという本製品の色の意味論を、名前が物理現象として内包する。これは他のどの候補にもない偶然の一致で、ワードマーク(REFRACT の字が分光していく)からダークモード「夜の製図台」でのプリズム表現まで一直線。弱点は審査1の指摘通り「指示書という成果物まで名前が届かない」ことと、**衝突チェック未実施**。採用検討時は Unprompt と同じゲートを通すこと。
- **対抗B: TACIT**(審査3で71点、衝突未確認)
  UNSAID の意味論(暗黙の判断の明示化)を、衝突ジャンルを外れた別の語で継承する保険。T…T 左右対称5文字は明朝全大文字ヒーローで最も静かに立ち、「静かな実測表示」というデザイン言語と気質が揃う。指示書画面の見出し "Your tacit decisions, made explicit." が製品説明を兼ねる。弱点: 日本語話者に読み(タシット)と意味が即通らず、評価基準2で構造的に失点。衝突未確認。**UNSAID が失われたことを惜しむ場合の意味論的後継**であり、音・伝達では Unprompt に劣る。
- **次点(条件付き対抗): Predraft**(221点、risk=high のため推薦不可)
  記録として残す: high 判定の根拠は predraft.ai(AI SEOツール)のほぼ完全一致であり、全 high 候補の中では衝突相手が単一。将来もし当該サービスが消滅すれば再浮上しうるが、**現時点では推薦しない**。

### 6.3 不採用の確定(risk=high)

UNSAID(249) / SUBTEXT(231) / Redline(225) / Predraft(221) / Presolve(75) — いずれもスコアに関わらず規定により推薦対象外。§6.0 の通り、スコア上位3案が全て high である事実は「この製品の意味領域(言外・裏・朱書き)は英語圏AIツール名として既に混雑している」ことの証拠であり、造語(Unprompt)側へ倒す判断を支持する。
