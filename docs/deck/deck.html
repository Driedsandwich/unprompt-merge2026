PROBLEM

生成AIもフォームも「意図は言語化済み」と仮定する。曖昧な依頼の空白は、読み手(人間/AI)が勝手な事前分布で埋め、誰の意図でもない成果物と修正往復が生まれる。

  • 人間は「自分が何をまだ決めていないか」を、自分では見えない。

SOLUTION

文がUIになる、1ループ

1 曖昧語
一文の中の語(「温かみ」「モダン」…)がそのまま判断点になる
2 帰結レンダ
語に係留された対照レンダリング対が並ぶ — 言葉で聞かず、帰結で問い返す
3 二動詞
〈決める〉か〈委ねる〉。委任は破棄ではなく「AIに委ねた」という明示情報
4 収束
原文の語が確定色/委任グレーに変わり、「この文から抽出した判断点 N」が0へ
二重憲法 その一
AIはユーザーの成果物を書かない。
(分岐ラベル・対照レンダ・根拠文は書く — この区別がスコープ限定の理由)
二重憲法 その二
人間は最初の一文以降、一度もタイプしない。残るのは選択だけ。
終了状態
全語が色分けされた原文+意図の指示書(人間可読の整形表示+機械可読JSON)。そのままAIへ手渡す。
脚注: 提示解釈がどれも不適合な場合の〈弾く〉は「不適合という情報」としてブリーフに記録する設計(v1設計済み・P0では単純さのため封印)。
