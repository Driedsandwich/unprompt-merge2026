# DISCLOSURE — 開示リスト

審査員・第三者への開示事項を列挙する場所。事前生成・キャッシュ・演出・APIキーの扱いなど、誤解を招きうる要素はすべてここに追記する。追記のみ、削除しない。

## 現時点の開示項目

| # | 項目 | 内容 | 影響 |
|---|---|---|---|
| 1 | ブラウザ直叩き構成 | Anthropic Messages API を `anthropic-dangerous-direct-browser-access: true` でブラウザから直接呼ぶ。中間サーバ・プロキシは存在しない | ユーザー自身のAPIキーを自身のブラウザで使う検証用途に限定。公開ホスティングには不適 |
| 2 | sessionStorage キー | APIキーは画面入力後 sessionStorage にのみ保存。タブを閉じると消える。コード・リポジトリ・localStorage には保存しない | 同一タブ内のスクリプトからは読める。共有マシンではタブを閉じること |
| 3 | クライアント計測 | レイテンシ・判定ログはすべてクライアント(ブラウザ)側で計測・エクスポートする。サーバ側の中立ログはない | 計測値はクライアント時計とネットワーク環境に依存する |
| 4 | Claude Code サブスクリプション経由の実行 | 主経路の実行は Anthropic API キーではなく、Claude Code サブスクリプションの headless CLI(`claude -p`)経由で行う。ブラウザ直叩き(#1)は API キー保有者向けの代替経路 | 実行にはログイン済みの Claude Code 環境が必要。API キーのみの環境では代替経路(#1)を使用する |
| 5 | レイテンシの分離記録 | レイテンシは `duration_api_ms`(API 実時間)と壁時計時間(CLI 起動オーバーヘッド込み)を分離して記録する | CLI 起動込みの壁時計値は API 実時間より大きく出る。両者を混同した提示はしない |
| 6 | デモ・動画でのプロキシ常駐 | デモ・動画では常駐プロキシ(claude -p を子プロセスとして呼ぶ Python 標準ライブラリサーバ)により CLI 起動オーバーヘッドを amortize する予定 | デモの体感レイテンシは単発 CLI 実行より短くなる。単発実行時の壁時計値とは別物として開示する |
| 7 | **並置比較(SplitCompare)は事前生成** | 画面 (g) で左右に並ぶ2枚の LP(`app/compare/raw.html` / `compiled.html`)は**デモ実行時にその場で生成していない**。`scripts/pregen_compare.py` で事前に実生成したものを iframe で表示する。`app/compare/manifest.json` に生成時刻・ブリーフ・決定一覧・各工程の `api_ms`・使用プロンプト全文・選択の機械照合結果を残す | 表示は事前生成物。ただし**キャッチではなく実生成物**であり、同じスクリプトを再実行すれば同じ経路で再生成できる。並置に要した時間はデモの体感時間に含まれない |
| 8 | 並置比較の対照条件 | RAW 側と COMPILED 側は同一モデル(sonnet)・同一 `--effort`・同一タイムアウト・同一の「LP制作者」system 骨格。違いはユーザープロンプト(発注者の一文 / コンパイル済みブリーフ)のみ。COMPILED 側の system にのみ2項目の追加がある(視覚トークンの厳守指示 / 選択ラベルを HTML・CSS コメントとして埋める指示) | この system の非対称は manifest.json の `prompts` に両者全文で残す。「同じ条件で入力だけ変えた」と述べる際は、この2項目の追加も併せて述べる |
| 9 | 並置比較の視覚トークン反映範囲 | COMPILED 側 LP には各判断点の選択ラベルが HTML/CSS コメント `GYAKUMON-CHOICE:` として埋まり、`manifest.json` の `verification.compiled` で機械照合している(RAW 側は 0 件の対照)。ただし**判断点ごとに独立生成される視覚トークン(パレット等)は互いに矛盾しうるため、LP に実装されるのはその一部**である | 「選択が全て反映される」と述べる場合の「反映」は、ラベル単位の追跡可能性を指す。パレット等のトークンは全判断点分が同時に実装されるわけではない。manifest の `decisions[].tokens` に全トークンが残るので差分は検証できる |
