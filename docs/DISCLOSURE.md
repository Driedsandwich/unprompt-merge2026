# DISCLOSURE — 開示リスト

審査員・第三者への開示事項を列挙する場所。事前生成・キャッシュ・演出・APIキーの扱いなど、誤解を招きうる要素はすべてここに追記する。追記のみ、削除しない。

## 現時点の開示項目

| # | 項目 | 内容 | 影響 |
|---|---|---|---|
| 1 | ブラウザ直叩き構成 | Anthropic Messages API を `anthropic-dangerous-direct-browser-access: true` でブラウザから直接呼ぶ。中間サーバ・プロキシは存在しない | ユーザー自身のAPIキーを自身のブラウザで使う検証用途に限定。公開ホスティングには不適 |
| 2 | sessionStorage キー | APIキーは画面入力後 sessionStorage にのみ保存。タブを閉じると消える。コード・リポジトリ・localStorage には保存しない | 同一タブ内のスクリプトからは読める。共有マシンではタブを閉じること |
| 3 | クライアント計測 | レイテンシ・判定ログはすべてクライアント(ブラウザ)側で計測・エクスポートする。サーバ側の中立ログはない | 計測値はクライアント時計とネットワーク環境に依存する |
| 4 | Claude Code サブスクリプション経由の実行 | 主経路の実行は Anthropic API キーではなく、Claude Code サブスクリプションの headless CLI(`claude -p`)経由で行う。ブラウザ直叩き(#1)は API キー保有者向けの代替経路 | 実行にはログイン済みの Claude Code 環境が必要。API キーのみの環境では代替経路(#1)を使用する |
| 5 | レイテンシの分離記録 | レイテンシは `duration_api_ms`(API 実時間)と壁時計時間(CLI 起動オーバーヘッド込み)を分離して記録する | CLI 起動込みの壁時計値は API 実時間より大きく出る。両者を混同した提示はしない |
| 6 | デモ・動画でのプロキシ常駐 | デモ・動画では常駐プロキシ(claude -p を子プロセスとして呼ぶ Python 標準ライブラリサーバ)により CLI 起動オーバーヘッドを amortize する予定 | デモの体感レイテンシは単発 CLI 実行より短くなる。単発実行時の壁時計値とは別物として開示する |
