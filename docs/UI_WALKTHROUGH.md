# UI_WALKTHROUGH — 画面に出る文言の全転記

対象: `app/index.html`(2026-07-30 時点)。利用者が見る順に、画面上の可視文言を過不足なく転記する。
装飾・レイアウト・色の記述は含めない。**文言と、それが出る条件だけ**を書く。
ペルソナ試験(利用者役に読ませて詰まる場所を探す試験)の入力として使う。

記法:
- `〈…〉` は実行時に決まる値(利用者の入力・モデルの出力・実測値)。
- 「常時」= その画面にいる限り必ず出る。それ以外は出現条件を書く。
- モデル由来の文(判断点の問い・選択肢のラベル等)は文言が固定でないので、`〈…〉`として枠だけ示す。

## 3. 判断点の画面(カードが出てからまとめるまで)

### 3-1 カウンタの行

| 位置 | 文言 | 出現条件 |
|---|---|---|
| 右 | `この文がまだ決めていないこと(判断点)を抽出中… 〈いま出ている件数〉` | 判断点がまだ増える可能性があるあいだ(受信中、および §3-7 の取り直し中) |
| 右 | `この文から抽出した判断点 〈総数〉 ・ 未決 〈未決数〉` | 総数が確定した後は常時 |
| 右端(ボタン) | `すべて委ねる` | 総数が確定していて、かつ未決が1件以上あるとき。受信中は出ない。未決0でも出ない |
| `すべて委ねる` にポインタを重ねたとき | `未決をまとめて任せる。あとで1件ずつ選び直せます。`(ツールチップ) | 同上 |

`すべて委ねる` を押すと、未決の判断点がすべて「委ねた」になる(1件ずつ `委ねる` を押したのと同じ)。押した後も、原文の語をクリックすれば1件ずつ選び直せる。

### 3-2 判断点カード(最大5枚)

| 位置 | 文言 | 出現条件 |
|---|---|---|
| カード見出し | 〈判断点の問い〉(モデル出力。空なら `(判断点)`) | 常時 |
| 見出しの下 | 〈決めないと壊れるものの説明〉(モデル出力) | モデルがその欄を返したときだけ |
| 選択肢のラベル | 〈選択肢の名前〉(モデル出力。空なら `オプション 1` `オプション 2` …) | 未決のあいだ |
| 選択肢の見本の中 | `見本が未着(このまま選べます)` | その選択肢の見本の取得に失敗したとき |
| 選択肢にポインタを重ねたとき | 〈その選択肢の見え方の説明〉(モデル出力・ツールチップ) | モデルがその欄を返したときだけ |
| カード右下(ボタン) | `委ねる` | 未決のあいだ |
| `委ねる` にポインタを重ねたとき | `選ばずに任せる。あとで選び直せます。`(ツールチップ) | 未決のあいだ |
| 最初のカードだけ・一番下の小さな字 | `見本をクリックすると決まる。決めないなら「委ねる」。どちらも、あとで選び直せます。` | まだ1件も決めても委ねてもいないあいだだけ。最初の操作で消え、以後は二度と出ない |

### 3-3 決めた後・委ねた後のカード

| 位置 | 文言 | 出現条件 |
|---|---|---|
| 小見出し | `決めた` | 選択肢を選んだカード |
| その下 | 〈選んだ選択肢のラベル〉 | 同上 |
| 小見出し | `委ねた` | `委ねる` または `すべて委ねる` を押したカード |
| その下 | 〈制作者に委ねたときの既定解〉(モデル出力。空なら `制作者(AI)の裁量に委ねる`) | 同上 |
| 見本の代わり | `制作者(AI)の裁量` | 委ねたカード |
| 一番下の小さな字 | `原文の語をクリックすると選び直せます` | そのカードが原文の語と結ばれているとき |
| 一番下の小さな字 | `この決定をクリックすると選び直せます` | そのカードが原文の語と結ばれていないとき |

### 3-4 まとめるボタン

| 位置 | 文言 | 出現条件 |
|---|---|---|
| カードの下・中央 | `指示書にまとめる` | 総数が確定し、かつ未決が0件のとき。1件でも選び直すと消える |
| 同上(押した後) | `まとめています… 〈経過秒〉s` | ボタンを押してから指示書画面に切り替わるまで |

### 3-5 判断点が0件だったとき

| 位置 | 文言 | 出現条件 |
|---|---|---|
| 原文の下 | 〈残った曖昧さについての所見〉(モデル出力) | 判断点0件で、モデルが所見を返したとき |
| 原文の下 | `この依頼文は十分に特定されている。抽出すべき判断点はない。` | 判断点0件で、所見が空のとき |

カードは1枚も出ず、`指示書にまとめる` はすぐ押せる状態で出る。

### 3-6 エラーの帯(原文のすぐ下)

| 文言 | 出現条件 |
|---|---|
| `問いの抽出に失敗しました(〈エラー内容〉)` / 続けて `server.py が起動しているか確認してください。` / ボタン `書き直す` | 通信そのものが失敗し、判断点が1件も出せなかったとき |
| `問いの抽出に失敗しました: 〈エラー内容〉` / 続けて 〈サーバからの助言〉 / ボタン `書き直す` | サーバがエラーを返し、判断点が1件も出せなかったとき |

`書き直す` はページを読み込み直す(最初の画面に戻る)。

### 3-7 受信が途中で切れたときの帯(カードの下)

| 文言 | 出現条件 |
|---|---|
| `判断点の受信が最後まで届きませんでした。全件を取り直しています…` / 続けて `既に出ている判断点と、あなたが決めた内容はそのまま残ります。` | 取り直しの最中 |
| `受信が途中で切れたため、全件を取り直して照合しました・既出 〈N〉 件は決定ごと保持 / 追加 〈M〉 件。` / 続けて `判断点の総数はこの照合で確定しました。` | 取り直しに成功したとき |
| 上の文に続けて `・取り直し側に現れなかった既出 〈K〉 件も残しています` | 取り直し側に無い判断点が既に画面に出ていたとき |
| `判断点を最後まで取得できませんでした(〈理由〉 / 再取得も失敗: 〈エラー内容〉)。` / 続けて `出ている判断点と決定は保持しています。総数が確定していないため、まだ指示書にまとめられません。` / ボタン `再取得` `書き直す` | 取り直しにも失敗したとき |

〈理由〉に入る文言は次の3つのいずれか:
- `接続が途中で切れた`
- `ストリームが最後まで届かなかった`
- `抽出が途中で失敗した(〈エラー内容〉)`

〈エラー内容〉が取れなかったときは `不明なエラー` と出る。
取り直しに失敗しているあいだ、カウンタは `この文がまだ決めていないこと(判断点)を抽出中… 〈件数〉` のままで、
`すべて委ねる` も `指示書にまとめる` も出ない(総数が確定していないため)。

|---|---|---|
| 枠の見出し | `意図の指示書` | 常時 |
| その横 | `compiled brief` | 常時 |
| 枠の中・左 | `あなたがタイプした文字` + 〈数〉 | 常時 |
| 枠の中・右 | `あなたの選択` + 〈数〉 | 常時 |
| タブ・左 | `読む用` | 常時 |
| タブ・右 | `AIに渡す用` | 常時 |
| 右端(ボタン) | `コピー` | 常時 |
| 同上(押した後) | `コピーした` | コピーに成功したとき(約1.6秒で `コピー` に戻る) |
| 同上(押した後) | `コピー失敗` | コピーに失敗したとき(約1.6秒で `コピー` に戻る) |
| 本文の下 | `本文の組み立てはブラウザ側の決定論処理。AIが書いたのは各判断点の「意図」1文のみ。 問いを組み立てた時間 〈N〉秒(早送りなしの実測) / 指示書にまとめた時間 〈N〉秒。` | 常時 |
| 同上・続けて | `意図の生成は失敗した: 〈エラー内容〉` | 意図(根拠文)の生成に失敗したときだけ。エラー内容が取れなかったときは `根拠文の生成に失敗しました` |
| 下(ボタン) | `この指示書でAIに作らせると?` | 常時 |
| 一番下(ボタン) | `最初から` | 常時(押すとページを読み込み直す) |

### 4-1 「読む用」タブの本文

出る順に、見出しと定型行だけを転記する(〈…〉は実行時の値)。

```
# 意図の指示書 (compiled brief)

## 発注者が書いた唯一の文

> 〈利用者が送信した一文〉

- あなたがタイプした文字(最初の一文以降): 〈数〉
- あなたの選択: 〈数〉
- 沈黙(送信→最初の判断点, 実測・早送りなし): 〈N〉秒
- 全判断点の確定まで(実測・早送りなし): 〈N〉秒
```

最後の2行は逐次受信できたときの表記。一括で受け取ったときは次の1行になる。

```
- 抽出の沈黙(実測・早送りなし): 〈N〉秒
```

判断点が0件だったときだけ、次が入る。

```
## 判断点

抽出された判断点は 0 件。この依頼文は十分に特定されている。
```

決めた判断点が1件以上あるとき。

```
## 決めた判断点

### 〈判断点の問い〉

- 選択: 〈選んだラベル〉
- 見え方: 〈選択肢の見え方の説明〉
- 原文の根拠語: 「〈語〉」「〈語〉」
- 見た目の指定: 色 〈色〉 / 〈色〉 / 〈色〉、見出しの書体=〈書体〉、余白の密度=〈密度〉、角の形=〈角〉
- トーン例: 〈見本の文〉
- 未解決なら壊れるもの: 〈説明〉
- 意図: 〈AIが書いた1文〉
```

(`見え方` `見た目の指定` `トーン例` `未解決なら壊れるもの` `意図` の各行は、その材料があるときだけ出る)

委ねた判断点が1件以上あるとき。

```
## 委ねた判断点(制作者=AIの裁量)

### 〈判断点の問い〉

- 委任: 制作者(AI)の裁量に委ねる
- 原文の根拠語: 「〈語〉」「〈語〉」
- 既定解: 〈既定解〉
- 未解決なら壊れるもの: 〈説明〉
- 意図: 〈AIが書いた1文〉
```

末尾は常に次のとおり。

```
## 残存曖昧度

〈モデルの所見〉        ← 所見が無いときは (評価なし)

## 発注者からの提供が必要な材料

- 〈材料〉              ← 1件も無いときは - (なし)

---

この指示書は、上の1文と 〈N〉 回の選択だけから GYAKUMON が機械的に組み立てた。
本文の文言は発注者の原文と選択ラベルに由来する。AIが生成したのは各「意図」の1文のみ。
```

意図の生成に失敗したときだけ、最後にもう1行入る。

```
注: 意図の生成に失敗した(〈エラー内容〉)。本文は選択だけから組み立てられている。
```

### 4-2 「AIに渡す用」タブの本文

JSON の上に、このタブを開いているあいだだけ1行の断りが出る(既定の「読む用」では出ない)。

| 位置 | 文言 | 出現条件 |
|---|---|---|
| 本文の上 | `この欄はコピーして、制作を任せるAIに渡すためのもの。人が読む必要はありません。` | 「AIに渡す用」タブを開いているあいだだけ |

JSON がそのまま出る。画面に見える見出し語(キー名)は次のとおり。

`format`(値は `gyakumon.compiled_brief.v0`) / `source_brief` / `compiled_at` /
`evidence`(`typed_characters_after_brief` `choice_count` `extraction_silence_ms`
`extraction_all_branches_ms` `extraction_streamed` `extraction_recovery` `extraction_timing`
`compile_wall_ms` `compile_timing` `rationale_error`) /
`decisions`(`question_point` `anchor_words` `status` `chosen` `default_if_unresolved`
`rationale` `downstream_impact`) / `residual_ambiguity_assessment` / `missing_materials`

## 6. 「処理の内訳」(左下・閉じているのが既定)

送信した後、判断点の画面・指示書の画面・並置画面のあいだ、左下に出たままになる。
閉じているときは見出しの1行だけ。押すと開き、もう一度押すと閉じる。

| 位置 | 文言 | 出現条件 |
|---|---|---|
| 見出し | `処理の内訳` | 送信後は常時 |

開いたときの中身。

### 6-1 固定情報

| 左の欄 | 右の欄 | 出現条件 |
|---|---|---|
| `実行エンジン` | `Claude Code CLI(ローカル実行・APIキー不使用)` | サーバに繋がっていて、APIキーを子プロセスへ渡さない設定のとき(既定) |
| `実行エンジン` | `Claude Code CLI(ローカル実行・APIキーを子プロセスへ渡す設定)` | `--allow-api-key` を付けて起動したとき |
| `実行エンジン` | `未取得` | サーバに繋がらなかったとき |
| `モデル` | `問いの抽出 〈モデル名〉 / 見本の生成 〈モデル名〉 / 指示書 〈モデル名〉` | サーバに繋がっているとき(値はサーバが答えた実際の設定) |
| `モデル` | `未取得` | サーバに繋がらなかったとき |
| `接続先` | `〈待受アドレス〉:〈ポート〉 のみ`(既定では `127.0.0.1:8321 のみ`) | サーバに繋がっているとき |
| `接続先` | `127.0.0.1 のみ` | サーバに繋がったが、待受アドレスを答えない古いサーバのとき |
| `接続先` | `未取得` | サーバに繋がらなかったとき |
| `プロンプト` | `リポジトリ 〈ディレクトリ名〉 で公開`(既定では `リポジトリ prompts/ で公開`) | 常時 |

### 6-2 このセッションの実測

処理が済むたびに行が増える。まだ1つも済んでいないあいだは次の1行だけ。

| 文言 | 出現条件 |
|---|---|
| `まだ実行された処理はありません。` | 実測の行が1行も無いあいだ |

| 左の欄 | 右の欄 | 出現条件 |
|---|---|---|
| `問いの抽出` | `model 〈モデル名〉 ・ api 〈N.N〉秒 ・ 判断点 〈数〉 ・ 棄却 〈数〉 ・ 二重確認 なし` | 判断点の総数が確定した後 |
| `問いの抽出` | `model 〈モデル名〉 ・ api 〈N.N〉秒 ・ 判断点 〈数〉 ・ 棄却 〈数〉 ・ 二重確認 あり` | 同上で、判断点0件のため自動でもう1回引き直したとき |
| `見本の生成` | `〈数〉件 ・ 平均 〈N.N〉秒 ・ 最長 〈N.N〉秒` | 見本が1つでも届いた後 |
| `見本の生成` | 上に続けて `・ 未着 〈数〉件` | 取得に失敗した見本があるとき |
| `指示書の根拠文` | `api 〈N.N〉秒 ・ 実測 〈N.N〉秒` | `指示書にまとめる` を押して応答が返った後 |
| `指示書の根拠文` | 上に続けて `・ 失敗` | 根拠文の生成に失敗したとき |

値が取れなかった秒数は `—` と表示する(数字を作らない)。
