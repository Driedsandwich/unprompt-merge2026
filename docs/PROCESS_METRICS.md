# プロセスログ要約 — AI共創の記録と時間短縮指標

提出要件「プロセスログ(AI対話記録、時間短縮指標)」への回答。生の記録は下記の各ファイルにあり、本書はその索引と実測指標の要約である。

## AI対話・共創の記録(実物への索引)

| 記録 | 場所 | 形式 |
|---|---|---|
| AIの提案 / 人の判断 / 採否と理由 | `PROCESS_LOG.md` | 3列表・全開発判断を時系列で記録 |
| 判断点タグ付きコミット | `git log`(`resolved: <判断点>→<決定> / 理由`) | 開発判断とコードの1対1対応 |
| 開示リスト | `docs/DISCLOSURE.md`(22項・追記のみ) | 事前生成・編集・例外の全開示 |
| 実行の生データ | `EVIDENCE/`(キラーテスト結果JSON・テスト出力・編集仕様) | 未編集 |

役割分担: 人間(管制塔)=意味判定・裁定・レビュー / AI(Claude Code)=実装・検証・編集。本製品の思想(文→分岐→決定)と同じ文法で開発した(デック⑦)。

## 時間短縮指標(実測・出典つき)

| 指標 | 実測 | 出典 |
|---|---|---|
| 構想(審議決定)→動く一気通貫 | 開発開始から **2時間** でエンジン品質実測(キラーテスト・UIなし)、**Day 1** で爆散→レンダの実データ一気通貫 | PROCESS_LOG / EVIDENCE/killer_test/ |
| 開発全体 | 開発切替(7/29)から提出(7/31)まで **実質3日** — 製品UI・エンジン・テスト群・動画・デックまで | PROCESS_LOG / git log |
| 抽出レイテンシの工学 | api **97〜123秒 → 8.8〜15秒**(約10分の1)+起動オーバーヘッド約1秒化。実測に基づく4段階の決定 | EVIDENCE/killer_test/GATE1_DECISION.md |
| 対照レンダ | **40秒 → api 4.1秒/壁5.0秒**(モデル選定の実測比較) | PROCESS_LOG |
| デモ動画の制作 | 収録(AI がブラウザ操作を代行・1テイク)→編集→QA→ユーザー確認まで **約1時間**。人間の作業は視聴確認のみ | EVIDENCE/demo_video/EDIT_SPEC.md |
| 品質担保 | DOMテスト10本+スパンテスト4000項+並置回帰+Python 4本を各変更ごとに全実行(人手の回帰確認をほぼゼロ化) | EVIDENCE/streaming/ ほか |

注: 「AIなしでの所要時間」との対照実験は行っていないため、倍率の主張はしない。上表は全て一次記録から辿れる実測値のみ。
