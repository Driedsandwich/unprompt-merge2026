# デモ動画 v1 編集仕様(2026-07-31 深夜収録)

成果物: `docs/deck/unprompt_demo_v1.mp4`(1920×1080 / 30fps / H.264 CRF18 / yuv420p / AAC48k無音 / faststart / 121.9秒 / 7.1MB)

## 収録方法(事実)

- 収録: 管制塔が ffmpeg 8.1.2(avfoundation)で Mac 内蔵 Retina 画面(2940×1912)を 30fps で全画面キャプチャ。299.9秒・1テイク。
- 操作: 管制塔が Chrome 拡張(claude-in-chrome)経由で実施(タイプ・クリック・スクロール全て)。人間の手操作はなし。カーソルは拡張の仮想カーソルが画面に描画されたものが映っている。
- タイプは type アクションを6分割+待機で実行(一文を分節ごとに入力)。
- 対象: `http://127.0.0.1:8512/?theme=light`(QA常駐サーバ・明テーマ・一時URLパラメータ)。
- クロップ: `crop=2836:1595:104:291` → scale 1920×1080。ブラウザのツールバー・拡張の「デバッグを開始しました」バナー・タブサイドバー・OS領域を全て除外(qa_grid_v1.png で確認)。
- 生素材: `raw/take1_full.mp4`(git管理外・170MB)。

## タイムライン(raw秒 → セグメント・速度・テロップ)

| seg | raw区間 | 速度 | テロップ |
|---|---|---|---|
| A | 3.0–17.5 | 1x | 曖昧な一文を、そのままタイプする |
| B | 17.5–34.0 | **1x(等速)** | 生成しない。問いを組み立てる ― 静寂 17.8秒(実測・等速) |
| C | 34.0–146.0 | 14x | 5つの判断点と見本を実生成中(×14倍速) |
| D | 146.0–159.0 | 1x | 見本をクリックで「決める」。決めないなら「委ねる」 |
| E | 159.0–179.0 | 4x | 残りはAIのおすすめで(×4倍速) |
| F | 179.0–186.0 | 1x | 未決 0 ― おすすめの理由も明示される |
| G | 205.0–210.0 | 1x | 意図の指示書へコンパイル |
| H | 210.0–235.0 | 4x | コンパイル中(×4倍速) |
| I | 235.5–277.0 | 1.75x | タイプは最初の一文だけ ― 選択5回・追加タイプ0字(×1.75倍速) |
| J | 277.0–299.5 | 1x | 同じ指示書で作らせた実例 ―「一文だけ」との並置 |

- ジャンプカット: 186–205(未決0後の無操作)と 299.5–299.9 を割愛。
- **誠実性規律**: 「静寂17.8秒」の主張区間(B)は等速。倍速をかけた区間は全てテロップ内に×Nを焼き込みで開示。数値(17.8秒/選択5回/追加タイプ0字)は画面内のアプリ自身の表示と一致。
- テロップ: ヘッドレスChromeで透過PNG化(Hiragino Kaku Gothic ProN・#15171C 78%帯・強調 #e8b27d)→ overlay 合成(このffmpegはdrawtext非搭載のため)。
- 再現: `build_demo.sh`(raw素材と telops/ があれば同一出力を再構築可能)。
