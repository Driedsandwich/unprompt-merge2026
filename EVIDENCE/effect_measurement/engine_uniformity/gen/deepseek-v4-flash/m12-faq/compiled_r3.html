RETURN GUIDE

返品のこと、ゆっくり一緒に確認しましょう

ご検討中の方も、お手続き中の方も、このページですべての条件と手順を明らかにします。
迷ったら各項目を開いてご確認ください。

📦

返品できる？ できない？

商品を開封したけど返品できますか？

未使用品に限り、到着後〈日数〉以内であれば開封済みでもお受けしております。ただし一部の商品（衛生用品・ダウンロードコンテンツ等）は対象外です。詳しくは条件一覧をご確認ください。

イメージと違った場合も返品対象ですか？

はい、「お客様都合」による返品として承ります。その際の返送料はお客様ご負担となります。到着後〈日数〉以内にご連絡ください。

返品できない商品を教えてください
返品不可の対象
・一度ご使用いただいた商品（衛生上・安全上の理由）
・お客様のもとでキズ・汚損が生じた商品
・〈確認: 具体的な商品カテゴリ例〉
お手元に届いた時点で不良・破損があった場合
上記にかかわらず交換・返品対応いたします。到着後〈日数〉以内にご連絡ください。

手続きの流れ・必要なもの

返品の手順を教えてください

以下の流れでお進みください。

  1. マイページまたはお問い合わせフォームから返品申請を行う
  2. 当店から返品受付番号と返送先をメールでお知らせ
  3. 商品を梱包し、指定された宛先へ発送
  4. 当店到着後、〈確認: 処理日数目安〉以内に返金手続き

返送時の送料は、不良品の場合は当店負担、お客様都合の場合はお客様負担です。

箱や説明書がないと返品できませんか？

可能な限り元の状態でお送りください。付属品が不足している場合、査定額が変動する可能性があります。箱がない場合でもお受けしますので、ご連絡ください。

返金はいつ・どのように行われますか？

当店で商品を確認後、〈日数〉営業日以内にご指定の口座へお振り込みいたします。クレジットカード決済の場合はカード会社を通した返金処理となります（反映時期はカード会社のサイクルによります）。

送料・期限・条件をすべて明記

返品できる期間と送料負担を教えてください
返品受付期限
商品到着日を含めて〈日数〉日以内
返送料の負担
不良品・誤配送 → 当店負担（着払い発送）
お客様都合（イメージ違い・サイズ間違い等） → お客様負担
交換の場合
在庫がある商品に限り交換対応可能。再送料は当店負担。
セール品・予約商品も同じ条件ですか？

セール品も上記の条件が適用されます。ただし、最終セール等で「返品不可」と明記した商品は対象外です。予約商品はお届け後、一般商品と同じ条件でお受けします。
