Works

〈作品タイトル1〉

Branding / Print

クライアントの要望は「一目でそれとわかるアイデンティティ」。そこで既存の競合分析から始め、差別化の軸を〈確認: 具体的な差別化軸〉に設定。ロゴから名刺・封筒・Webまで一貫したトーンで展開した。 判断点：色数を3色に制限した理由は、印刷コストと記憶への残りやすさのバランスを取るため。

〈作品タイトル2〉

UI / Digital

サービスのコア体験を「迷わないこと」と定義。情報設計の段階でユーザーの行動パターンを3パターンに分類し、それぞれに最適な導線を設計した。結果として離脱率が〈確認: 改善前後の数値〉改善。 判断点：トップページの情報量を極限まで削ったのは、初回訪問者のスクロール離脱データが根拠。

〈作品タイトル3〉

Editorial / Design System

年次報告書のリデザイン。情報量が多く、読み手の属性が幅広いという課題に対し、本文・補足・データで3層の情報階層を定義。タイポグラフィと余白のルールを厳密に定めることで、どのページを開いても一貫した体験になるよう設計した。 判断点：グリッドを8列から12列に変更したのは、図版と本文の比率を細かく調整するため。
