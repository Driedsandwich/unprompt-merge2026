この勉強会について

秋の社内勉強会は、部署や職種の垣根を越えて、日々の業務から生まれた気づきや課題を共有する場です。今回のテーマは「〈テーマ〉」。社内の誰かが実際に試した手法や、困っていること、面白いと思った視点を持ち寄り、対話を通じて学びを深めます。

見どころ

01　社内の実践知が聞ける

書籍や記事では読めない、同じ職場の仲間が経験した試行錯誤や成果を直接聞けます。

02　分野を越えた対話

普段話す機会のない部署の人ともテーブルを囲み、新しいつながりを作ります。

03　秋の夜長にゆっくり学ぶ

暑さが落ち着いた季節に、集中して知見を吸収できる時間を確保します。
