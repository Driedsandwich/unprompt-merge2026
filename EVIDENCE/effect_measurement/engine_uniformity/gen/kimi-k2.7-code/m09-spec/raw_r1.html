経費精算ツール仕様メモ

目的

社員の経費精算で発生する手入力の手間と領収書の紛失を減らし、会計担当の月次集計を効率化する。

対象ユーザー

出張・打ち合わせなどで経費を発生させる全社員と、支払いを確認する会計担当者。

主要機能

  • 領収書の写真をアップロードし、日付・金額・店名を自動読み取り、手動で修正できる。
  • 経費科目とプロジェクトタグを選択し、利用目的を短くメモできる。
  • 申請一覧で未申請・承認待ち・差戻しを色分けし、合計金額をリアルタイムで表示する。
  • 月次締めに必要なCSVを出力する。
  • 会計担当が承認・差戻しのステータスを更新し、差戻し理由を入力できる。

画面イメージ

トップは日付順のカード一覧。右上に当月の合計金額を表示し、右下の＋ボタンでカメラ撮影またはアップロードを起動する。詳細画面では、領収書画像のプレビューと入力欄を並べ、PCでは左右配置、スマホでは縦に積む。

使わないと決めたもの

  • 多階層の承認ワークフローエンジン
  • クレジットカードや会計システムとのAPI連携
  • 外貨や複数通貨の換算機能
  • ネイティブアプリとしての開発
  • 紙帳票の印刷機能
