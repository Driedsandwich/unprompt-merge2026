経費精算、自動で締まる。

集計・経理処理を自動化し、月次締めを即完了できる状態にする。申請者の入力補助ではなく、経理担当者が受け取ったデータを仕訳・集計・検証する作業を削減する。

対象ユーザー

経理担当者。専用アプリではなく、既存のExcel/スプレッドシート上で動作する。

主要機能

  • 領収書データを定型フォーマットに貼り付けるだけで、自動で科目・税区分・金額を集計
  • 月次仕訳データをワンクリックで出力
  • 入力ミス・金額不整合を自動検知し、該当行を強調表示
  • 締め日を指定すると対象期間のデータのみを抽出

画面イメージ

シートの左側に未処理データを貼り付ける列、右側に自動集計結果が並ぶ。貼り付けた時点で処理済みのマークがつき、不整合があれば強調色で行全体が示される。下部に「今月の仕訳を出力」ボタンのセルがあり、押すと新しいシートに仕訳一覧が展開される。

使わないと決めたもの

  • スマホカメラでの領収書撮影機能
  • 会計システム〈既存会計システム名〉との連携
  • 承認フロー機能
