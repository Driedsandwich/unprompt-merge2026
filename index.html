INTENT COMPILER — 実生成ギャラリー
AIは、あなたの成果物を一文字も書かない。あなたの意図だけを、書かせる。
ここにあるのは、Unprompt の指示書で実際に作らせた成果物の並置比較です。
このページは静的なギャラリーです。対話体験(爆散→決める/委ねる→指示書)はローカルで動きます: git clone https://github.com/Driedsandwich/unprompt-merge2026.git && cd unprompt-merge2026 && python3 server.py
必要なのは Claude Code にログイン済みの環境だけ(APIキー不要・ビルド不要)。疑似再生のデモは置いていません — 動くところは動画とローカルで。

並置比較 — 同じ一文、渡し方だけが違う

タイトルをクリックで左右並置。左(朱)=発注者の一文をそのまま渡した結果 / 右(藍)=Unprompt の指示書を渡した結果。モデル・思考量・制作者プロンプトの骨格は左右同一。生成痕跡マーカーとmanifestによる機械照合つき。
